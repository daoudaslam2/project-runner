# Code of Conduct

Project Runner is a small developer tool, and contributions should stay useful, respectful, and focused.

## Expected Behavior

- Be respectful and constructive.
- Keep discussions relevant to the project.
- Give clear context when reporting problems.
- Assume good intent when reviewing issues or pull requests.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Spam, trolling, or repeated off-topic comments.
- Sharing private information without permission.

## Enforcement

Project maintainers may edit, hide, or remove comments, issues, or pull requests that do not follow this code of conduct.
