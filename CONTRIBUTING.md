# Contributing

Thanks for helping improve Project Runner.

## Development

Install dependencies:

```bash
npm install
```

Compile:

```bash
npm run compile
```

Lint:

```bash
npm run lint
```

Package locally:

```bash
npx @vscode/vsce package
```

## Pull Requests

- Fork the repository.
- Create a feature branch.
- Keep changes focused.
- Run `npm run compile` and `npm run lint` before opening a PR.
- Describe what changed and how you tested it.

Pull requests must pass CI before they can be merged.
